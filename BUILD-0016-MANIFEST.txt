NEW IN THIS BUILD
- Full native persistence implementation is now present instead of only the save/load bridge declarations.
- Save files use a fixed magic/version header plus payload-size validation and FNV-1a checksum.
- Save writes go through a same-directory temporary file before replacement.
- Truncated, corrupt, incompatible, or malformed saves are ignored without partially applying state.
- Persisted state covers player/body pool, resources/progression, fabrication, wreck, enemy, boss, ecosystem clock/history/chunks/actors, and dormant-population progress.
- Dormant ecosystem populations retain fractional birth/death progress so aggregate ecology changes over time instead of rounding every simulation tick away.
- Aggregate distant food-chain pressure is simulated: grazer resource use and hunter predation affect dormant populations.
- HUD now shows ECOACTIVE/TOTAL conceptual population.
- Minimap cell density uses total active + dormant population so distant life remains visible in world-scale map data.
- Local ecology readout shows ACTIVE/TOTAL for the current chunk.

SAVE FORMAT
- Schema version: 3
- Header: magic, version, payload size, checksum
- Payload is explicitly serialized field-by-field rather than dumping C++ structs.
- Existing older schema saves are ignored and a fresh deterministic world can be initialized.

ACTIVE SIMULATION
- 96 individual actor slots remain the detailed simulation ceiling.
- Nearby creatures receive full hunger/thirst/energy/fear/group/target behavior.
- Distant populations remain represented by chunk-level aggregates.
- The conceptual world population can exceed the active actor count.
