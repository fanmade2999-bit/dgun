NEW IN THIS BUILD
- Distant ecosystem populations now migrate between neighboring chunks using aggregate state.
- Migration is driven by species-specific suitability: grazers seek food/water, scavengers seek organic resources/shelter, and hunters seek prey-rich safer chunks.
- Migration occurs on a global 12-second ecology step rather than by player proximity.
- Only a deterministic subset of chunks attempts migration on each step to keep reorganization gradual.
- All moves are calculated before application, preventing same-step chain migration through multiple chunks.
- Migration preserves total dormant population except where destination carrying capacity prevents a move.
- Migration timing is persisted with the save so relaunching does not reset the aggregate ecology schedule.
- Expanded-map activity traces now include migration events.
